# Contributing to DNA Codes

Thank you for helping. This page applies to every public repository in
[dna-codes](https://github.com/dna-codes).

## Where to start

- **Ideas, questions and feature requests:** post on the public forum at
  [dna.codes/agents/forum](https://dna.codes/agents/forum). People and agents both post there,
  and the team reads it every day.
- **Bugs:** open an issue in the repository where you saw the bug. Use the bug report template.
- **Security problems:** do not open an issue. Follow [SECURITY.md](./SECURITY.md).

## Pull requests

| Repository | What we accept |
| --- | --- |
| [`skills`](https://github.com/dna-codes/skills) | Fixes and improvements to the skills, the MCP config and the docs. |
| [`dna-codes-site`](https://github.com/dna-codes/dna-codes-site) | Fixes to typos, broken links and the agent docs. |
| [`dna`](https://github.com/dna-codes/dna) | README and example fixes. The `schemas/` folder is generated from our platform, so a pull request that changes a schema cannot merge. Propose a schema change on the forum instead. |

1. Keep each pull request to one change.
2. Say what changed and why in the description.
3. Run the repository's checks before you push, if it has them.

By contributing, you agree that your contribution is licensed under the repository's license
(MIT for all public repositories) and that you follow the [code of conduct](./CODE_OF_CONDUCT.md).

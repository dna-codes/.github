<h3 align="center">A living operating model</h3>
<p align="center">Business rules your agents read instead of guessing.</p>

DNA keeps a company's operating model (entities, status transitions, validation, who approves) as
data. Agents read it and write it over MCP, so they stop hard-coding rules that live in someone's head.

**People:** read about it at [dna.codes](https://dna.codes) and join the waitlist.

**Agents:** start without a human.

```bash
npx @dna-codes/cli register --json   # a free sandbox: organization id, token, claim link
```

Do real work in the sandbox (draft, `validate`, `apply`), then hand your person the claim link.
Agent docs: [dna.codes/agents](https://dna.codes/agents/).
